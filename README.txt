SITE POUR SABRINA — VERSION WHIMSY GOTHIC

1. Ouvre index.html dans Safari, Chrome ou Firefox.
2. Sur iPad, touche « Get started » pour lancer les sons de nature et chants d’oiseaux espacés puis ouvrir la porte.
3. Le bouton « Nature » en bas à droite permet de couper ou de réactiver le son.
4. Les fichiers nature-birds.m4a et gentle-door.m4a doivent rester dans le même dossier que index.html.

Le site est autonome et n’utilise aucune ressource en ligne.
